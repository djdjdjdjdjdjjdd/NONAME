=======================================
함수 호출 방식: Call-by-value와 Call-by-reference

Call-by-value는 값 전달 방식으로, 외부 변수에 영향을 주지 않는다

Call-by-reference는 주소 또는 참조자를 통해 값을 전달하여, 외부 변수에 영향을 준다

참조자를 이용한 Call-by-reference는 안전하고 효율적이다
_______________________________________________________________
매개변수는 함수가 호출될 때 선언이 되는 변수이므로 함수 호출의 과정에서 선언과 동시에 전달되는 대상으로 초기화된다

즉, 매개변수에 선언된 참조자는 여전히 선언과 동시에 초기화 된다
=======================================
const 참조자와 안전성

const 참조자는 값을 변경하지 않는 함수에 적합하다.

상수는 임시 저장되어 참조 가능하며, 값 변경이 불가능하다

const 참조자를 사용하면 실수로 값이 변경되는 것을 방지할 수 있다

매개변수는 함수가 호출될때 선언이 되는 변수이므로 함수
호풀 과정에서 선언과 동시에 전달되는 대상으로 초기환된다

즉, 매개변수에 선언돤 청조자는 여전히 선언과 동시에 초기화된다

#include <iostream>

void swapbyReference(int& ref1, int& ref2) {
	int temp = ref1;
	ref1 = ref2;
	ref2 = temp;

{
	int val1 = 10;
	int val2 = 20;

	swapbyReference(val1, val2);

	cout << "val2: " << val2 << endl;

}

delete

=======================================
생성자는 클래스의 이름이랑 똑같고 출력이 없다

생성자(constructor): 객체를 만들기 위해서 생성자가 호출되며, 객체를 초기화하는 역할을 한다.
입력이 없는 생성자는 자동으로 만들어진다
만약 명시적으로 생성자를 만들면 , 디폴트 생성자는 호출되지 않는다.

입력이 없는 생성자는 디폴트 생성자라고 말한다


객체를 사용하려면 생성자를 만들어줘야한다
 (주요 용도)
객체가 생성될 때 멤버 변수(필드)를 초기화하거나
객체가 사용할 필수적인 초기 설정(메모리 할당 등)을
미리 해두기 위해 사용합니다.
생성자가 없다면 객체를 만든 뒤 일일이 값을 넣어줘야 하는 번거로움이 생깁니다.

생성자를 쓸때는 문법을 조심해야한다
객체 생성문법, 함수의 선언 문법이 있는데 조심해서 사용해야한다
=======================================
CONST 를 붙이는 이유는 값이 변하지 않는 상태로 받기 위해서 이다

절대로 바뀌면 안 되는 중요한 값을 코드로 고정해 두어, 실수로 값을 변경하는 버그를 원천 차단합니다.
